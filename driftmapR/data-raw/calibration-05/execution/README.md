# Study 05 execution implementation

This directory implements the immutable parent `README.md` and
`analysis-contract.md`. It does not replace that design freeze. The installed
public engine remains driftmapR 0.0.7.9000. No candidate covariance adjustment,
effective-unit correction, spectral tolerance, delivery gate, target, cell,
seed, or budget is selected from the evaluation outcomes.

## Lifecycle

From the package root, with the pinned public engine installed:

```sh
Rscript data-raw/calibration-05/execution/test.R /absolute/engineering-evidence.rds
Rscript data-raw/calibration-05/execution/freeze.R /absolute/engineering-evidence.rds
Rscript data-raw/calibration-05/execution/run.R /absolute/study05-output 8
```

The test command uses only seed779/dataset999 measurement fixtures. The freeze
requires clean test evidence matching every implementation file and verifies all
91 original design dependencies. It additionally fingerprints the installed
public engine. An existing lock cannot be overwritten. The runner refuses an
absent lock or any source, plan, or engine mismatch.

Before generating any evaluation measurement panel, the runner saves all 1,640
jobs and all 326,360 planned integer weight vectors and RNG streams. It then
executes the unchanged case-major plan with at most eight independent outer
workers, serial inner computations and `mc.set.seed=FALSE`. Every worker uses
the explicit frozen stream. Scheduling never supplies randomness.

## Durable accounting and resumption

Each completed checkpoint has a separate content checksum, full job/seed record,
and design/implementation/plan identity. Resumption checks all of them before
reading or reusing its scientific contents. Atomic partial files are preserved
as infrastructure incidents, including their hashes. Corruption, worker errors,
and interrupted validation are infrastructure failures; they never become
statistical non-delivery rows or trigger replacement panels. A completed numerical
result is saved as a pending checkpoint before mechanical validation and physical
audit, preserving discrepancies for diagnosis. Successful finalization removes
only that redundant, verified pending copy.

Generation, collection, and validated completion have separate markers. The
final marker is written only after all 1,640 checkpoints, their mechanical
reconstructions, 31 physical audits, complete collection, and frozen analyses.
Never interpret the completed subset of an interrupted run as the full design.

Checkpoints retain scalar geometry and full stage/deletion ledgers; dataset1 in
every case additionally retains detailed matrices and all inner deletion vectors.
Large tidy draw and pivot tables are gzip-compressed CSV. Compact analysis inputs,
audits, accounting totals, source/engine identities and session information are
separate inspectable artifacts. Target views and frame registrations are not
counted as independent eigenfits.

## Diagnostic interpretation

The main region targets the full declared-anchor functional theta_D. Inclusion
of theta_C is separately labeled target sensitivity. The eight-anchor point
diagnostic supplies no clean-anchor bootstrap region. AR(1) cells intentionally
violate the iid-unit resampling/studentization contract; their known Gram variance
inflation is descriptive and never changes m or a cutoff.

Observed-gap strata use the observed two-period minimum gap/lambda1. The literal
all-core-stage anchor-conditioning minimum includes attempted candidate baseline
and temporal stages, including required deletions. An observed-only conditioning
view is an auxiliary diagnostic. Both exclude direct-A, evaluation-only and clean
diagnostic registrations. These post-data cohorts are not gates or claims of
conditional nominal coverage.

The inherited operational evaluator blocks subsequent work if its observed
registration into the population chart fails. The implementation distinguishes
an available observed core fit, evaluation registration availability, and an
evaluation-only block. In that last case computational candidate region delivery
is unknown (NA), study-evaluable delivery is false, and coverage is unavailable.

Public PCA and classical-MDS checks account explicitly for the public adapter's
warning at a spectral boundary versus the research kernel's frozen rejection.
That prescribed difference is classified separately from numerical disagreement;
it does not relax the candidate's rejection rule or permit redraws.

The parent analysis contract is authoritative for every output and denominator.
Successful implementation tests or audits do not establish nominal coverage.
